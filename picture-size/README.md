# 批量调整图片尺寸（Word 加载项）

按最小尺寸筛选并批量调整 Word 文档中的图片尺寸，支持自动适应页面宽度（减 1 厘米，等比缩放）。

## 文件说明

- `index.html`：任务窗格页面（含内联 CSS/JS）
- `manifest-picture.xml`：加载项清单文件

## 使用方式

### 1. 启动 HTTPS 服务器

```powershell
npx http-server "e:/A001 重要软件/OFFICE加载项/word-addin" -p 8080 -S -C "$env:USERPROFILE/.office-addin-dev-certs/localhost.crt" -K "$env:USERPROFILE/.office-addin-dev-certs/localhost.key" --cors
```

### 2. 加载清单

- Word → 文件 → 选项 → 信任中心 → 信任中心设置 → 受信任的加载项目录
- 添加共享目录，勾选"同时信任此网络共享位置"
- 重新启动 Word

### 3. 使用加载项

在"开始"选项卡中点击**"调整图片尺寸"**按钮。

## 功能

### 范围
- **当前文档**：直接通过 Word JS API 调整
- **多个 Word 文档**：解析 docx 文件，处理后打包下载

### 限定要修改的图片
- **全部图片**：不限制，全部处理
- **限制最小尺寸**：仅调整宽度和高都**大于**指定值的图片（比如只调整大图，不调整小图标）

### 修改后尺寸
- **自动适应页面宽度**：自动检测当前文档页面宽度，目标宽度 = 页面宽度 − 1 厘米，高度等比缩放
- **指定宽度**：手动输入目标宽度（CM），高度等比缩放

### 图片类型
- 嵌入式图片
- 浮动图形
- 文本框（内的图片）

## 注意事项

- 调整操作不可撤销，建议先保存文档。
- 尺寸单位为 CM，等比缩放保持原始宽高比。
- 多文档模式下页面宽度默认为 A4（21 CM），或使用最近一次检测到的页面宽度。
